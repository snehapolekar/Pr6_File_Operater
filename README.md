# 📔 Personal Journal Manager

## 📌 Project Description

Personal Journal Manager is a Python-based application that helps users manage their daily journal entries. Users can add new entries, view saved entries, search for specific entries, and delete entries. The application stores journal information in a file, and new entries include the current date and time.

## ✨ Features

### ➕ Add a New Entry

Users can add their daily thoughts and journal entries. The current date and time are recorded with the entry.

### 👀 View All Entries

Users can view all the journal entries saved in the journal file.

### 🔍 Search for an Entry

Users can search for journal entries using a keyword or date.

### 🗑️ Delete Entries

Users can delete journal entries after confirming their choice.

### 📋 Menu-Driven Program

The application provides a simple menu where users can select different options to manage their journal.

## 🛠️ Technologies Used

* Python
* Object-Oriented Programming (OOP)
* File Handling
* Exception Handling
* Date and Time Module

## 📂 Project Functionality

The application provides the following options:

1. Add a New Entry
2. View All Entries
3. Search for an Entry
4. Delete an Entry
5. Exit
